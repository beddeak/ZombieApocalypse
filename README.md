# 좀비 아포칼립스

마크에서 좀비 아포칼립스가 일어나는 플러그인입니다.

## 서버 준비

마크 **Java Edition 26.2**로 들어올 수 있게 **Paper 26.2 서버**를 준비해 주세요. 서버 실행에는 **Java 25**가 필요합니다.

[Releases](https://github.com/beddeak/ZombieApocalypse/releases/latest)에서 `ZombieApocalypse-0.2.0.jar` 받아서 서버 `plugins` 폴더에 넣고 서버를 다시 켜면 됩니다. OP 받은 상태에서 `/apoc start` 치면 시작이고, 끄려면 `/apoc stop` 치면 됩니다.

"동물을 제외한 모든 적대적 몬스터들이 좀비로 대처됩니다"

## 좀비 종류

- **기본 / 스프린터** — 일반 좀비랑 엄청 빠른 좀비.
- **부머 / 봄버** — 부머는 죽고 나서 터지고, 봄버는 가까이 와서 자폭합니다.
- **스로어 / 그래버 / 점퍼** — 날려버리거나, 갈고리로 당기거나, 높은 곳까지 뛰어와서 덮칩니다.
- **맹독 / 프로스트 / 흡혈귀** — 독이랑 허기를 걸거나, 얼리거나, 때린 만큼 체력을 회복합니다.
- **닌자 / 클라이머 / 텔레포터** — 평소에 투명하거나, 벽을 타고 오거나, 등 뒤로 순간이동합니다.
- **증식 / 네크로맨서** — 죽으면 분열하거나 땅에서 좀비를 일으킵니다.
- **스크리머 / 힐러** — 비명 질러서 좀비를 부르거나 주변 좀비를 회복시킵니다.
- **스피터 / 블레이즈** — 바닥에 산성 웅덩이를 깔거나 불덩이를 쏩니다.
- **필러 / 자키 / 도둑** — 좀비끼리 탑을 쌓거나, 머리에 올라타거나, 인벤토리 아이템을 떨어뜨립니다.
- **위치** — 울고 있는 애. 얼굴 쳐다보거나 정면으로 가까이 가면 달려옵니다.
- **탱크** — 블록 부수면서 쫓아오는 보스. 바위도 던지고 불에 약합니다.
